## 📊 Vehicle Dataset Analysis - Questions & Objectives

This project explores a vehicle sales dataset to extract actionable insights using Python and Pandas. Below are the key questions answered during the analysis:

### 🔍 Data Exploration Objectives:

1. **Manufacturing Year Range**  
   - From which manufacturing year to which manufacturing year are vehicles present in this data?

2. **Price Range**  
   - What is the lowest price at which a vehicle was sold?  
   - What is the highest price at which a vehicle was sold?

3. **Dataset Overview**  
   - How many total records are there in the dataset?  
   - Are there any missing (null) records in this dataset?

4. **Vehicle Diversity**  
   - How many different vehicle models are present in the dataset?

5. **Popularity Analysis**  
   - Which is the most sold vehicle in the dataset?

6. **Fuel Type Check**  
   - Does the database include any CNG vehicles? If yes, how many?

7. **Seller Type Analysis**  
   - How many vehicles are being sold directly by individuals?

8. **Transmission Type**  
   - Does this database contain auto-transmission vehicles? If yes, how many?

9. **Ownership Status**  
   - How many single-owner vehicles are there in the dataset?

10. **Depreciation Analysis**  
   - Which vehicle has the most and least cost depreciation?

11. **Brand Stability**  
   - Which brands are less affected by cost depreciation?

12. **Depreciation Factors**  
   - What factors seem to affect cost depreciation? (e.g., age, kilometers driven)

13. **Age vs Price & KMs vs Price**  
   - Is the selling price affected by age and kilometers driven? Can it be observed from data?

14. **Newest Vehicles**  
   - Can we identify vehicles manufactured after 2014?

---

### 🏍️ Two-Wheeler Analysis:

15. **Two-Wheelers Filtering**  
   - Can we extract only two-wheelers from the dataset?

16. **Bike Age Range**  
   - Which is the oldest bike sold?  
   - Which is the newest bike sold?

17. **Popular Bike**  
   - Which is the most sold bike?

18. **Exceptional Two-Wheeler Deals**  
   - Any two-wheeler deal that exceeded general expectations? Why?

---

### 🚗 Car Analysis:

19. **Cars Filtering**  
   - Can we extract only cars from the dataset?

20. **Car Age Range**  
   - Which is the oldest car sold?  
   - Which is the newest car sold?

21. **Exceptional Car Deals**  
   - Any car deal that exceeded general expectations? Why?
